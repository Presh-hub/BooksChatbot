# 📚 Books ChatBot

An interactive chatbot that helps users discover books, search for titles, and get summaries.

---

## 🚀 Features

- 📖 List all books
- 🟢 Beginner, 🟡 Intermediate, 🔴 Advanced recommendations
- 🔍 Search books by keyword
- 🧠 Get book summaries
- 💬 Interactive chatbot (CLI + Web)
- 🌐 Streamlit web app interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- JSON (data storage)
